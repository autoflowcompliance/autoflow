Questions.

Where does my client's data go?

It's processed in memory to build the report and isn't used for anything else. You can delete a workspace's files at any time. A self-hosted licence is available if the data can't leave your network.

Is it an AI guess?

No. The checks are deterministic rules and schema mappings, so the same file gives the same report every time, and every number traces back to the rows behind it.

Which systems does it read?

Any CSV, Excel or JSON export. Target schemas ship for HubSpot, Salesforce, Pipedrive, Zoho CRM, Zoho Books, Dynamics 365, NetSuite, Xero, QuickBooks, FreshBooks, Freshsales, Close, Attio, Airtable, Insightly, monday.com, Sage and Wave.
