FAQ

Questions.

Where does my client's data go?

It's processed to build the report and isn't used for anything else, and you can delete a workspace's files at any time. If the data can't leave your network, a self-hosted licence is available.

Is it an AI guess?

No. The checks are deterministic rules and schema mappings: the same file gives the same report every time, and every number traces back to the rows behind it.

Which target systems are supported?

18 target schemas, including HubSpot, Salesforce, Pipedrive, Zoho CRM, Zoho Books, Dynamics 365, NetSuite, Xero, QuickBooks and monday.com. Any CSV, Excel or JSON export can be read.
